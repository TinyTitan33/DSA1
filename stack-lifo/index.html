What "balanced" means

  • ( [ ] ) is balanced.
  • ( [ ) ] is not — ( closes while [ is still open.
  • ( ( ) is not — one ( is never closed.

Why a stack solves it (LIFO)

  • Opening bracket → push it onto the stack.
  • Closing bracket → pop the top (it must match).
  • At the end → the stack must be empty.
